# Evidence-sufficiency audit — instructions

Each item shows a research question (intervention vs comparator on an outcome)
and ONE excerpt annotated as the evidence for it. Using only the excerpt:

sufficient — Y if the excerpt lets you determine the effect of the intervention
             relative to the comparator on this outcome; N if it does not (wrong
             outcome, wrong comparison, no direction stated, ambiguous).
label      — if sufficient, one of INCREASE / DECREASE / NO_DIFFERENCE
             (significantly increased / decreased / no significant difference).
             Leave blank if not sufficient.
note       — optional.
