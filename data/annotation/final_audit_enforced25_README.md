# Final-answer audit (enforced 25-token condition) — instructions

Each item shows a research question (intervention vs comparator on an outcome),
the ANNOTATED EVIDENCE from the source article, and a pipeline's final ANSWER.
Judge the answer's claim about the effect ONLY against the evidence.

supported        — Y if the answer's stated effect (direction and whether it is a
                   real/significant effect) matches the evidence; N otherwise.
failure_type     — if N: qualifier (significance/qualifier changed), mutation
                   (direction reversed), omission (effect not stated / not
                   mentioned), weakening (hedged into uncertainty); "-" if Y.
nodiff_to_effect — Y if the evidence says no significant difference but the
                   answer asserts an effect; else N.
Items are in random order; model and condition are hidden.
